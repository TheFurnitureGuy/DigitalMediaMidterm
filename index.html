Why does it look different?

RGB values

Screens make every color by mixing red, green and blue light. Each channel has a value from 0 to 255, so one pixel can show about 16.7 million colors. For example, rgb(255, 140, 0) is a bright orange.

Palettes and quantization

A palette is a fixed set of colors an image is allowed to use. Quantization picks a palette for your photo, then replaces each pixel with the closest color in it. So several similar blues in a sky can all become one blue.

Dithering

With only a few colors, smooth areas like a sunset sky break into visible bands. Dithering places palette colors next to each other in a pattern. From a normal viewing distance, your eye blends them into shades the palette doesn’t have. Many PS2 games used ordered dithering, which repeats a small grid pattern instead of spreading the rounding errors around.

What does each setting change?

Some settings reduce part of the image. Others change it before the palette is chosen.

Output resolution

Fewer pixels

Resolution sets how many pixels the image has. Lower resolution makes the image smaller and loses fine detail, but each pixel can still use any color in the palette. Softness is different. It shrinks the picture and enlarges it again, so fine detail is lost but the pixel count stays the same.

Palette size

Fewer colors

Palette size sets how many different colors the image can use. The number of pixels stays the same. The size is a maximum, so a simple image can end up using fewer colors.

Look settings

New shades first

Glow, fog, brightness, color strength, tint, grain and the TV effect change the photo before the palette is chosen. They add new shades, such as a soft haze in the sky, so the palette ends up with different colors. The pixel count stays the same.

Why PS2 games looked like this

The presets copy tricks PS2 games used to set a mood or to work around the console’s limits. Each one adds new shades before the palette is chosen, which is why the same palette size can look so different.

Fog

Fog in Silent Hill 2 makes the town feel closed in and uneasy. Many games of that time also used fog to hide how little of the world the console could draw at once.

Glow

Shadow of the Colossus spreads bright light into its surroundings, an effect called bloom. Highlights look washed out, and the whole land seems to glow.

Color filters

Metal Gear Solid 3: Snake Eater lays a green, sepia-like filter over the whole picture, which gives its jungle a warm, faded look.

CRT TVs

PS2 games were made for CRT TVs. The scanlines and soft picture of a CRT hid jagged edges, so games looked smoother on a TV than in a sharp screenshot.
