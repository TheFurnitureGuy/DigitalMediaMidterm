Why does it look different?

RGB values

Screens make every color by mixing red, green and blue light. Each channel has a value from 0 to 255, so one pixel can show about 16.7 million colors. For example, rgb(255, 140, 0) is a bright orange.

Palettes and quantization

A palette is a fixed set of colors an image is allowed to use. Quantization picks a palette for your photo, then replaces each pixel with the closest color in it. So several similar blues in a sky can all become one blue.

Dithering

With only a few colors, smooth areas like a sunset sky break into visible bands. Dithering places palette colors next to each other in a pattern. From a normal viewing distance, your eye blends them into shades the palette doesn’t have. Many PS2 games used ordered dithering, which repeats a small grid pattern instead of spreading the rounding errors around.

What does each setting change?

Each setting reduces a different part of the image.

Output resolution

Fewer pixels

Resolution sets how many pixels the image has. Lower resolution makes the image smaller and loses fine detail, but each pixel can still use any color in the palette.

Palette size

Fewer colors

Palette size sets how many different colors the image can use. The number of pixels stays the same. The size is a maximum, so a simple image can end up using fewer colors.

Polygon detail

Fewer triangles

Polygon detail sets how many triangles redraw the photo. Each triangle is filled with one color, so fewer triangles means larger flat shapes. The pixel count and the palette don’t change.

Transcript

Every color on your screen is a mix of red, green and blue. Each one has a value from 0 to 255, so a single pixel can be one of about 16 million colors.

Quantization reduces that number. The image gets a small set of colors, called a palette, and each pixel is replaced with the closest color in it. So several similar blues might all become one blue.

With fewer colors, smooth areas like the sky start to show bands. Dithering helps with this. It places different palette colors next to each other in a pattern, and from a distance your eye blends them into a shade the palette doesn’t have.

Keep in mind that this changes the colors, not the size. Resolution sets how many pixels there are, and polygon detail sets how many triangles draw the photo.
