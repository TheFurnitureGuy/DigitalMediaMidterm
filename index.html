Why does it look different?

RGB values

Screens mix red, green and blue light, each from 0 to 255, so one pixel can show about 16.7 million colors. For example, rgb(255, 140, 0) is a bright orange.

Palettes and quantization

A palette is the fixed set of colors an image may use. Quantization picks a palette and swaps each pixel for its closest color, so similar blues become one blue.

Dithering

With few colors, smooth areas break into bands. Dithering mixes palette colors in a pattern your eye blends into in-between shades. Many PS2 games used ordered dithering, a small repeating grid.

What does each setting change?

Some settings reduce part of the image. Others change it before the palette is chosen.

Output resolution

Fewer pixels

Resolution sets the pixel count. Fewer pixels lose fine detail, but each can still use any palette color. Softness also blurs detail, but keeps the pixel count.

Palette size

Fewer colors

Palette size sets how many colors the image can use. The pixel count stays the same, and a simple image may use fewer.

Look settings

New shades first

Look settings like glow, fog, tint and the TV effect change the photo before the palette is chosen. They add new shades, so the palette ends up with different colors.

Why PS2 games looked like this

The presets copy tricks PS2 games used to set a mood or hide the console’s limits. Each adds new shades before the palette is chosen.

Fog

Silent Hill 2 uses fog to make its town feel closed in. Many games also used fog to hide how little they could draw at once.

Glow

Shadow of the Colossus spreads bright light into its surroundings, called bloom, so the land seems to glow.

Color filters

Snake Eater lays a green, sepia-like filter over the whole picture for a warm, faded jungle.

CRT TVs

PS2 games were made for CRT TVs, whose scanlines and soft picture hid jagged edges.

Read the transcript

Every color on your screen is a mix of red, green and blue. Each one has a value from 0 to 255, so a single pixel can be one of about 16 million colors.

Quantization reduces that number. The image gets a small set of colors, called a palette, and each pixel is replaced with the closest color in it. So several similar blues might all become one blue.

With fewer colors, smooth areas like the sky start to show bands. Dithering helps with this. It places different palette colors next to each other in a pattern, and from a distance your eye blends them into a shade the palette doesn’t have.

Keep in mind that this changes the colors, not the size. Resolution sets how many pixels there are. The look settings, like glow and fog, add new shades before the palette is chosen.
